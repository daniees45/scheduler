# 📁 CSV FILE ORGANIZATION - QUICK REFERENCE

## Directory Structure
```
csv/
├── general/          → Shared data (rooms, availability, curriculum)
├── department/       → Department-specific (courses, dept rooms)
├── final/           → Generated schedules (OUTPUT)
├── clean/           → Cleaned/preprocessed data
└── fos/             → Faculty-specific files
```

## Key File Locations

### Input Files (Read by system)
| File | New Location | Purpose |
|------|-------------|---------|
| departmental_courses.csv | `csv/department/` | Main course input |
| rooms.csv | `csv/general/` | General room pool |
| lecturer_availability.csv | `csv/general/` | Lecturer schedules |
| special_rooms.csv | `csv/general/` | Pre-assigned rooms |
| curriculum.csv | `csv/general/` | Course metadata |
| *_rooms.csv | `csv/department/` | Dept-specific rooms |

### Output Files (Generated by system)
| File | New Location | Purpose |
|------|-------------|---------|
| final_web_schedule.csv | `csv/final/` | Main output |
| exam_schedule.csv | `csv/final/` | Exam timetable |

## Code Usage

### Python
```python
from load_data import load_combined_data

# Defaults now use csv/ structure
data = load_combined_data(["csv/department/departmental_courses.csv"])

# Or rely on defaults (already set to csv/)
data = load_combined_data(["your_input.csv"])
```

### PHP
```php
// Read schedule
$csv = 'csv/final/final_web_schedule.csv';

// Export from DB
export_to_csv('csv/general/rooms.csv', $headers, $data);
```

## Web Interface
- **Upload files:** `web/import_data.php` - handles path automatically
- **Generate schedule:** `web/generate.php` - output goes to `csv/final/`
- **View schedule:** `web/view_schedule.php` - reads from `csv/final/`
